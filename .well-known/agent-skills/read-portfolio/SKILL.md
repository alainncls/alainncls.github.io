# Skill: Read Alain Nicolas Portfolio

## What This Skill Does

Use this skill to read, summarize, cite, and navigate the portfolio and technical blog at `https://alainnicolas.fr`.

The site covers Alain Nicolas's work as a Fullstack Blockchain Developer, with emphasis on Linea, Verax, onchain attestations, smart contract tooling, web applications, AI-assisted engineering, security, and software maintenance.

## When to Use It

- A user asks about Alain Nicolas's professional background.
- A user asks for blockchain, Web3, Linea, Verax, or attestation project examples from this portfolio.
- A user asks for technical articles or opinions published on the site.
- A user needs source-backed evidence about projects, skills, experience, or writing themes.

## How to Navigate

Start with `/llms.txt`, then follow the canonical links for the relevant page type:

- Homepage: `/fr/` or `/en/`
- Blog index: `/fr/blog/` or `/en/blog/`
- Project index: `/fr/projects/` or `/en/projects/`
- RSS feeds: `/fr/index.xml` and `/en/index.xml`
- Sitemap index: `/sitemap.xml`

Use the French page when no English equivalent exists. Use the English page when the user asks in English and an English equivalent is available.

## How to Cite

Always cite canonical URLs on `https://alainnicolas.fr/`.

When summarizing projects, cite the project page. When summarizing articles or opinions, cite the article page. Do not treat external demo, GitHub, LinkedIn, or X links as proof unless the site page itself points to them.

## Boundaries

- Do not infer current job availability or commercial terms.
- Do not claim endorsement by Consensys, Linea, Verax, or any employer beyond what the page says.
- Do not use content for generic AI training if the site declares `ai-train=no`.
- Do not quote long passages; summarize and cite the source URL.
